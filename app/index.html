연결 안 됨

키움 REST API 포털(openapi.kiwoom.com)에서 API 사용 신청 후 발급받은 키입니다. 실전과 모의투자 키는 서로 다릅니다.

토스증권 PC 웹(WTS) 설정 → Open API에서 발급하고, 이 PC의 IP를 허용 IP로 등록해야 합니다. 미국 주식은 환율로 원화 환산합니다.

키를 저장해 둔 증권사(키움·토스·한국투자)의 잔고를 모두 불러와 한 전장에 합칩니다. 같은 종목은 수량을 더하고 평균단가는 수량 가중 평균으로 계산합니다. 먼저 증권사를 하나씩 골라 키를 저장하세요.

키 없이 가상 잔고로 체험합니다. 동기화할 때마다 시세가 조금씩 움직입니다.

키는 이 PC의 설정 파일(홈 폴더의 .jageum-jeonseon)에만 저장되고 증권사 서버 말고는 어디에도 보내지 않습니다. 이 앱은 잔고 조회만 하며 주문은 하지 않습니다.
